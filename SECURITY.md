# Security policy

Please do not disclose a suspected vulnerability in a public issue before it can be reviewed.

Submit the affected version, Zen Cart and PHP versions, reproduction steps, impact, and supporting logs through the [PRO-Webs helpdesk](https://prowebsinc.zohodesk.com/portal/en/newticket). Remove passwords, API credentials, session identifiers, customer information, and unnecessary server paths.

Security support covers the current release. This free plugin is distributed without warranty.
